# Resolvedores de Problemas de Transporte

Portal web que agrupa distintos métodos de solución inicial para problemas de transporte:

- **Método de Costo Mínimo** (`resolvedor-costo-minimo/`)
- **Método de Esquina Noroeste** (`resolvedor-esquina-noroeste/`)

## Acerca del proyecto

Realizado como trabajo grupal para la materia "Modelos y Sistemas" del séptimo año de la tecnicatura secundaria en informática.
