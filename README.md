Aplicación web para calcular la solución inicial de problemas de transporte mediante dos métodos clásicos de investigación operativa:

- **Método de Costo Mínimo** (`resolvedor-costo-minimo/`): asigna priorizando las rutas de menor costo unitario.
- **Método de Esquina Noroeste** (`resolvedor-esquina-noroeste/`): asigna partiendo desde la celda superior izquierda avanzando por filas y columnas.

Permite definir orígenes, destinos, ofertas, demandas y costos unitarios, balancea automáticamente problemas desbalanceados con un nodo ficticio y exporta la matriz resultante a CSV.

Disponible en: [resolvedores.bautiavila.com](https://resolvedores.bautiavila.com)

## Acerca del proyecto

Realizado como trabajo grupal para la materia "Modelos y Sistemas" del séptimo año de la tecnicatura secundaria en informática.
